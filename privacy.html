Tiko Says Studio: Privacy Policy

Last updated: 4 November 2026

Tiko Says Studio is a private command-line tool used by the creator of the YouTube channel Tiko Says to manage that channel. It is not offered to the public and has one user: the channel owner.

What it accesses

With the channel owner's permission (Google OAuth, scopes youtube, youtube.force-ssl and yt-analytics.readonly), the tool uses the YouTube API Services to set the details and schedule of the channel's own videos, manage the channel's own subscriptions, post comments as the channel on public videos and read replies to them, and read the channel's own statistics and analytics.

What it stores

Only on the owner's own computer: the OAuth access token, a list of related channels (IDs, titles, public subscriber counts) a log of the actions the tool has taken, and the text of comments it has posted and replies to them.

What it shares

To draft comments, the tool sends the title, channel name and transcript of a public video, plus the channel's own earlier comments, to Anthropic's Claude. No OAuth tokens or analytics data are sent. Beyond that and Google's own services, no data is shared. Nothing is sold or used for advertising.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the local token file removes all stored credentials.
